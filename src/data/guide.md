# 从零开始：写出你的第一个 C++ 程序

> 这一页假设你**完全没有写过代码**。不需要你会任何编程知识，只要能看懂简单的英文单词。
> 花 10 分钟读完，你就能独立完成第一题。

---

## 一、先放心：你什么都不用安装

打开这个网页就能写代码。原因很简单：

- 这个网站把**真正的 C++ 编译器（clang）**编译成了浏览器能运行的形式（WebAssembly，简称 Wasm），
  所以你点"运行"时，编译和运行都发生在**你自己的电脑里**。
- 不需要注册、不需要联网判题，你的代码也不会被上传到任何服务器。
- 唯一的代价：第一次打开时需要下载约 90MB 的编译器（页面会有进度条），之后浏览器会记住它，再打开就很快了。

## 二、程序、语言、编译器：三个词就够了

| 词 | 大白话解释 |
| --- | --- |
| **程序** | 写给电脑的一系列指令，像一份菜谱：第一步做什么、第二步做什么，顺序不能乱。 |
| **编程语言（C++）** | 写这份菜谱用的语言。电脑其实只懂 0 和 1，所以需要有"人话"来写指令，C++ 就是其中一种。 |
| **编译器** | **翻译官**。它把你写的 C++ 翻译成电脑能执行的东西。翻译过程中如果发现你写错了（比如漏了标点），它会**拒绝翻译并告诉你错在哪一行**。 |

所以点"运行"按钮时，背后发生两件事：

1. **编译**：翻译官检查你的代码，翻译成电脑能执行的程序。写错了 → 你会看到**编译错误**，程序根本不会运行。
2. **运行**：翻译成功 → 立刻执行，你会看到**运行结果**。

> 重要观念：**看到报错是正常的**。职业程序员每天要看几十条报错。报错不是"你不行"，而是编译器在告诉你"这里有个字我不认识"。

## 三、认识题目页：左边看题，右边写代码

```
┌──────────────── 左边：题目要求 ────────────────┬──────────── 右边：你的代码 ────────────┐
│  题目名 / 难度 / 知识点                        │  工具栏：[重置代码] [运行] [提交]        │
│  题目背景 · 任务 · 输入格式 · 输出格式 · 样例   │  ┌────────────────────────────────┐   │
│  ▸ 提示（默认折叠，点开才显示）                 │  │  代码编辑器（在这里写代码）      │   │
│  参考题解（通过后解锁）                        │  └────────────────────────────────┘   │
│  [上一题]                          [下一题]    │  [标准输入] / [运行结果] 两个标签页      │
│                                                │  测试用例列表（提交后显示每条对错）      │
└────────────────────────────────────────────────┴────────────────────────────────────────┘
```

几个按钮的区别（**新手最容易搞混**）：

| 按钮 | 作用 |
| --- | --- |
| **运行** | 用"标准输入"框里你填的数据，跑**一次**程序，只把输出给你看。适合边写边试。 |
| **提交** | 把这道题的**所有测试用例**依次跑一遍，逐条比对输出。**全部通过**才算完成这道题。 |
| **重置代码** | 把编辑器恢复成最初的初始代码（你写的改动会丢掉）。 |
| **跳到我该写代码的地方** | 光标自动跳到 `// TODO` 那一行——不知道代码往哪写就点它。 |

## 四、逐行读懂你的第一段代码

打开第一题，右边的编辑器里已经有这段代码了。**它不是你写的，是给你准备好的"外壳"**：

```cpp
#include <iostream>          // ①
using namespace std;         // ②

int main() {                 // ③
    // TODO: 在这里写你的代码    // ④
    return 0;                // ⑤
}                            // ⑥
```

| 行 | 写法 | 它是什么意思（大白话） |
| --- | --- | --- |
| ① | `#include <iostream>` | 把"输入输出工具箱"拿进来。`iostream` 读作 *input output stream*（输入输出流），里面有负责打印的 `cout` 和负责读取的 `cin`。不写这一行，电脑就不认识 `cout`。 |
| ② | `using namespace std;` | 一句"偷懒声明"：以后写 `cout` 就行，不用写全名 `std::cout`。`std` 是标准库的名字空间（可以理解成"标准工具箱"）。**现在背下来照抄**，第 5 阶段之后你会真正理解它。 |
| ③ | `int main() {` | 程序的**入口**。电脑永远从 `main` 开始执行。`int` 表示"程序结束时我要还给系统一个整数"；`{` 之后的内容就是"要做的步骤"，直到对应的 `}` 结束。 |
| ④ | `// TODO: ...` | **注释**：以 `//` 开头的这一行是写给人看的，电脑**完全无视**。`TODO` 是英文"待办"的意思，这里的作用是告诉你**代码该写在哪**。 |
| ⑤ | `return 0;` | 程序结束，把 0 交给系统。**0 表示"一切正常"**（其他数字表示出了状况）。 |
| ⑥ | `}` | 和 ③ 里的 `{` 是**一对**，把 `main` 的内容包起来。漏了它会报错。 |

**你唯一要做的事**：在第 ④ 行的位置写一行输出语句。外壳的其他部分都**不用改**。

## 五、把一行输出语句拆开看

以第一题为例，你要写的那一行是：

```cpp
cout << "Hello, World!" << endl;
```

一个符号一个符号地拆开：

| 片段 | 怎么读 | 作用 |
| --- | --- | --- |
| `cout` | "C-out"（character output，字符输出） | 输出工具，负责把东西送到屏幕上。 |
| `<<` | 两个小于号 | 像一个小箭头，把**右边的东西送进左边**（送进 `cout`，也就是送到屏幕上）。 |
| `"Hello, World!"` | 双引号里的内容叫**字符串** | 要**原样**显示的文字。逗号后面的空格也要照写。注意：必须是**英文双引号** `"`。 |
| `endl` | "end line"（结束这一行） | 换行：让光标移到下一行，之后的输出从新的一行开始。 |
| `;` | 分号 | **一句的结束符**，像中文的句号。**每一句后面都必须有**，漏了立刻报错。 |

把它们连起来读就是：**"把 Hello, World! 送到屏幕上，然后换行。"**

如果要输出两行，就写两句：

```cpp
cout << "第一行" << endl;
cout << "第二行" << endl;
```

1. 在右边的编辑器里找到 `// TODO` 那一行（点工具栏的 **跳到我该写代码的地方**，光标会自动停在那里）。


## 七、新手最大的坑：中文标点

C++ 只认**英文半角**符号。用中文输入法打出来的标点是**全角**的，长得像但电脑完全不认识：

| 要用的（英文） | 常见错误（中文） | 说明 |
| --- | --- | --- |
| `"` `"` | `"` `"` | 引号：必须英文双引号，且**左右是同一个字符** |
| `;` | `；` | 分号：中文分号最常被误用 |
| `(` `)` | `（` `）` | 圆括号 |
| `,` | `，` | 逗号 |
| `:` | `：` | 冒号 |

**预防方法**：写代码时把输入法切到英文（按 `Shift` 或 `Ctrl+空格`）。
本站的编译器很贴心：一旦它发现你的代码里有中文标点，会在错误面板里**直接提示"检测到中文标点符号"并指出位置**。

## 八、报错不可怕：常见错误对照表

编译失败时，结果面板会列出错误，格式是 `第几行 : 第几列 : error: 具体说明`。
**点一下那条错误，编辑器会跳到对应行**；出错的行在编辑器里也会显示红色波浪线。

| 报错原文（英文） | 中文含义 | 怎么办 |
| --- | --- | --- |
| `expected ';' after expression` | 表达式后面少了个分号 | 上一行的结尾补上英文分号 `;` |
| `use of undeclared identifier 'cout'` | 不认识 `cout` | 检查 ① `#include <iostream>` 和 ② `using namespace std;` 是否还在；③ 是不是拼错了（`cout` 不是 `Cout`、`count`、`cour`） |
| `use of undeclared identifier 'x'` | 不认识 `x` | 变量名拼错，或没有定义，或大小写不一致（C++ 区分大小写） |
| `expected '}'` | 缺少右大括号 | 检查 `{` 和 `}` 是否成对 |
| `extraneous closing brace` | 多了一个 `}` | 删掉多余的 `}` |
| `invalid character` / 提示中文标点 | 用了中文标点 | 换成英文半角符号（见上一节） |
| `no matching function for call to ...` | 函数的参数个数或类型对不上 | 检查括号里的参数 |
| `warning: unused variable 'a'` | 警告：变量 `a` 定义了却没使用 | **警告不是错误**，程序照样能运行，可以先不管 |

**两条重要经验：**

1. **从第一条错误开始改**。后面的错误经常只是第一条引起的连锁反应，改完第一条再重新运行。
2. 报错说的是"**第几行**"，不是"整个程序都错了"。慢慢来，一次改一处。

## 九、小词典（不认识就回来查）

| 单词 | 读音/含义 |
| --- | --- |
| `cout` | C-out，输出（往屏幕上打字） |
| `cin` | C-in，输入（从键盘读数据） |
| `endl` | end line，换行 |
| `include` | 包含（把工具箱拿进来） |
| `main` | 主要的——程序的入口函数名，固定写法 |
| `return` | 返回（`return 0;` = 正常结束） |
| `int` | integer，整数 |
| `double` | 双精度小数（存小数用） |
| `string` | 字符串（存文字用） |
| `error` | 错误（必须改，程序不会运行） |
| `warning` | 警告（可以不改，程序能运行） |
| `expected` | 期望/需要（"这里应该有个 ……"） |
| `identifier` | 标识符（你起的名字，比如变量名） |
| `undeclared` | 未声明的（"这个名字我没见过"） |

## 十、给零基础同学的几条建议

1. **先自己写，卡住 10 分钟再看提示**；提示在左边题目描述的"提示"折叠区里，通过后还能看参考题解。
2. **不要死记**。忘了 `cout` 怎么写，就回来看这一页第五节的表格。
3. **一次只改一处，然后运行**。改了三个地方同时报错，你会不知道是哪一处引起的。
4. **按顺序做题**。题目是按知识顺序排的：输出 → 变量 → 判断 → 循环 → 数组 → 函数 → 结构体 → 哈希表。
   如果觉得被"闯关模式"卡住，可以在右上角关掉它，自由跳着练。
5. **进度自动存在你这台电脑的浏览器里**。换电脑时，去"我的进度"页面导出 JSON，在新设备上导入即可。
