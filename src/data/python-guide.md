# 从零开始：写出你的第一个 Python 程序

> 这一页不假设你学过编程。Python 的写法很接近日常英文，适合用来建立编程思维。

---

## 一、Python 是什么

**Python 是一种编程语言**：你用它把步骤写下来，电脑按顺序执行。它的特点是代码简洁、容易读，常用于数据分析、人工智能、自动化脚本和网站开发。

和 C++ 相比，Python 通常不需要写分号，也不需要在每条语句外包一层大括号；它用**缩进**表示“这一部分属于谁”。缩进不是排版习惯，而是语法的一部分。

## 二、第一行程序：输出文字

```python
print("Hello, World!")
```

`print` 的意思是“打印”。运行这段程序，屏幕会显示：

```text
Hello, World!
```

| 片段 | 作用 |
| --- | --- |
| `print` | Python 自带的输出工具。 |
| `(` 和 `)` | 把要输出的内容放进去。 |
| `"Hello, World!"` | 双引号中的文字叫字符串，会原样显示。 |

要输出两行，就写两次 `print`：

```python
print("第一行")
print("第二行")
```

## 三、变量：给数据起名字

变量像一个贴了标签的小盒子，用来记住数据。等号 `=` 在 Python 里表示“把右边的值存进左边这个名字”。

```python
name = "小明"
age = 12
print(name)
print(age + 1)
```

这里 `name` 保存文字，`age` 保存数字。Python 会根据你放进去的内容自动判断类型，所以初学时不必先写 `int`、`string` 之类的类型名。

> 注意：变量名不能有空格，建议用英文、数字和下划线，例如 `total_score`。名字不能以数字开头。

## 四、输入：让用户提供数据

`input()` 会等待用户输入一行内容。它拿到的是**文字**；若你需要做加减乘除，要用 `int()` 转成整数。

```python
name = input("你的名字是：")
print("你好，" + name)

number = int(input("请输入一个整数："))
print(number * 2)
```

刚开始写题时，在线评测一般不给提示文字，所以常写成：

```python
n = int(input())
print(n * 2)
```

## 五、判断：满足条件才做某件事

当程序需要“如果……就……”时，用 `if`。冒号 `:` 后面另起一行，并向右缩进四个空格。

```python
score = int(input())

if score >= 60:
    print("及格")
else:
    print("再努力一下")
```

| 写法 | 意思 |
| --- | --- |
| `==` | 是否相等；不要和赋值的 `=` 混淆。 |
| `>=`、`<=` | 大于等于、小于等于。 |
| `if` | 条件成立时执行下面缩进的代码。 |
| `else` | 条件不成立时执行下面缩进的代码。 |

## 六、循环：重复做一件事

`for` 循环适合“重复固定次数”。`range(5)` 会依次给出 `0、1、2、3、4`，一共五次。

```python
for i in range(5):
    print(i)
```

如果想从 1 数到 5，可以写 `range(1, 6)`：起点包含，终点不包含。

```python
total = 0
for i in range(1, 6):
    total = total + i
print(total)
```

## 七、列表：把一组数据放在一起

列表（`list`）就是按顺序装了许多数据的盒子。位置从 **0** 开始编号，这是编程中很常见的规则。

```python
fruits = ["苹果", "香蕉", "橙子"]
print(fruits[0])       # 苹果
print(len(fruits))     # 3

for fruit in fruits:
    print(fruit)
```

`fruits[0]` 是第一个元素，`fruits[1]` 才是第二个。`len(fruits)` 可以得到列表长度。

## 八、函数：把常用步骤打包

函数是给一段代码起名字，需要时再调用。`def` 表示“定义函数”。

```python
def say_hello(name):
    print("你好，" + name)

say_hello("小红")
say_hello("小刚")
```

函数内部的代码同样必须缩进。写得多了以后，函数能让程序更清楚，也避免重复复制同一段代码。

## 九、新手最常见的错误

| 现象 | 先检查什么 |
| --- | --- |
| `IndentationError` | 同一代码块的缩进是否一致；推荐每层固定四个空格，不要混用 Tab。 |
| `SyntaxError` | 是否漏了英文冒号 `:`、括号或引号；输入法是否打出了中文标点。 |
| `NameError` | 变量名是否拼错，或是否在赋值前就使用了它。 |
| `TypeError` | 是否把文字和数字直接相加；需要时用 `int()` 或 `str()` 转换。 |
| 结果少一次或多一次 | 检查 `range` 的终点：它不会被包含。 |

## 十、接下来怎么练

先练到能独立写出“读一个整数、判断奇偶、循环求和”这三类小程序。遇到报错时，先读最后一行：它通常会告诉你错误类型和位置。写代码本来就是“尝试、报错、修改、再运行”的循环。
